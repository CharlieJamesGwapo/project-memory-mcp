Project Memory gives AI assistants durable local project notes, explicit decision history, and handoffs through ten MCP tools.

- Native Rust server with bundled SQLite and no hosted service or paid model API requirement.
- Companion skills: resume-project, record-decision, and prepare-handoff.
- MCPB bundle: macOS Apple Silicon and Intel through a universal binary; Linux x64 with compatible glibc; Windows x64.
- Separate native archives are also available. Rust is only needed when building from source.

Download the MCPB for a compatible bundle client, or extract a native archive and configure its executable as a local stdio MCP server. Skills are included as files and installed separately using your client's skill mechanism. Setup details are in the repository README.

The database stays on your computer. Your AI client controls what retrieved memory is sent to its model. No chat history is ingested automatically. Binaries are not Developer ID signed or notarized.

All Linux, macOS, and Windows CI jobs and all four native build jobs passed. The source has 24 passing Rust tests, plus release-packaging checks. SHA256SUMS.txt records the published asset hashes.
