# Project Memory Toolkit 0.2.1

This patch fixes macOS Studio distribution while retaining all toolkit features
from [0.2.0](https://github.com/CharlieJamesGwapo/project-memory-mcp/releases/tag/v0.2.0):
12 MCP tools, budgeted whole-record context, unified search, four companion
skills with developer workflows, archive helpers and the desktop companion.

Studio now uses an explicit ad-hoc signing identity that seals the complete app
bundle. The v0.2.0 preview had only a linker-generated executable signature and
failed strict macOS bundle verification. Prefer the v0.2.1 Studio download.
Existing v0.2.0 assets and the Registry listing remain intact.

The publication workflow verifies the app before ZIP packaging and again after
extracting the exact ZIP, then generates checksums and provenance attestations.
Ad-hoc signing provides a resource integrity seal; it is not an Apple Developer
ID identity or notarization. Follow your operating system's trust controls.

The server's tool contracts and SQLite schema 1 are unchanged. See README.md,
docs/quickstart.md and docs/security.md for setup and current limits.
