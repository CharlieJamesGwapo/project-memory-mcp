## Security and review regressions

Independent reviewers reproduced audit startup side effects, collisions with
SQLite sidecars and case/Unicode aliases on an actual case-insensitive Mac.
Regressions now reject those destinations before creating an archive or audit
file. Existing archive bytes remained unchanged in six independent alias probes.
SDK malformed-argument errors no longer echo caller-supplied credentials.

Cross-platform CI exposed a late-startup success after an elapsed lock budget.
A deterministic expired-deadline test failed before the fix. Initialization now
checks elapsed time after commit and WAL setup as well as before operations;
the existing two-lock regression and independent follow-up passed. These checks
reject late successful startup, not forcibly interrupt every OS call at five seconds.

Review tests cover full schema-1 note compatibility, exact commits, supplied-head
freshness, complete canonical result budgets, scoped snapshot pagination,
cross-project/repository rejection, immutable revisions and concurrent fork
prevention. Additional external multi-page/full-record comparisons passed.
No outstanding material finding remained in the assigned independent reviews.

The three v2 skill scenarios each met six withheld criteria with fresh workers.
This small manual-rubric assessment establishes observed behavior in those
synthetic tasks, without a baseline comparison or model-wide improvement claim.
[Inputs, responses and method](https://github.com/CharlieJamesGwapo/project-memory-mcp/blob/v0.4.0/evals/project-memory/v2/observations.md)
remain available. The historical genuinely tool-disabled v1 scenario remains unrun.

## Limits

Archives/backups remain plaintext. Policy is per-connection capability restriction,
not authentication against another process with file access. Global-sequence
cursors expose activity metadata. Credential screening is incomplete; authorized
ordinary reads preserve existing records. Review freshness compares supplied
commit IDs and does not certify source or reported checks. Audit receipts and
SQLite commits are separate files, without cross-file atomicity.

Studio is a read-only macOS arm64 preview with ad-hoc signing, without Developer
ID/notarization. Frontend/native tests and production builds passed; no new full
native window click-through was performed for v0.4. Compile/test CI is not
interactive runtime proof for every OS. See [security](../security.md),
[access policy](../access-policy.md) and [review contracts](../code-review.md).
Source review, known-advisory scans, checksums and provenance provide scoped
evidence, not malware absence or a guarantee of future safety.
