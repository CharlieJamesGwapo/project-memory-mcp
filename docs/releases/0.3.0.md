# Project Memory MCP 0.3.0

This release makes setup and useful context easier while preserving local Rust
and SQLite storage, schema 1, all 12 MCP tools and existing literal defaults.

- Explicit `init` creates an empty archive and exits. Read-only terminal commands
  list project IDs, search memory, read complete records and print context briefs.
- Simultaneous writable clients serialize initialization and identity checks;
  WAL setup handles bounded lock contention without replaying memory writes.
- Opt-in ranked terms find words spread across fields and explain matches.
  Ranking considers coverage, headline matches and recency before the candidate
  window. Complete records, sources, byte accounting and omission notices remain.
- Studio offers Small/Balanced/Expanded presets, Custom advanced caps and explicit
  terms mode. Presets never fetch automatically or replace the selected brief.
- The same four-folder skill pack adds focused debugging and delivery-verification
  guides. Versioned fixtures support repeatable evaluation without a model API.

Native server downloads cover Linux x64, Windows x64 and both Mac architectures.
Studio remains a macOS Apple Silicon preview with verified ad-hoc bundle sealing,
no Developer ID identity and no notarization. The security guide retains current
upstream Linux desktop dependency warnings and actual check limits.

CLI Markdown/JSON size differs from the canonical MCP response used for retrieval
budgets. Token estimates are heuristics, not provider usage or guaranteed savings.
Saved material remains untrusted historical reference; the host supplies any
model, source tools, agents and authorization. Existing published assets remain intact.
