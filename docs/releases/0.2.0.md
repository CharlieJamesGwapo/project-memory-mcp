# Project Memory Toolkit 0.2.0

Project Memory now combines local project memory, a focused developer workflow
pack, and an optional desktop workspace.

- Twelve MCP tools, including literal search across notes/decisions/handoffs and
  whole-record context bundles with byte budgets, omission counts and original
  provenance. Explicit selections fit completely or return an error.
- One `project-memory` entry skill routes to token-saving, evidence-based code
  review, host-provided agent teamwork and security review. Three existing
  focused memory skills remain directly available, with older-server fallback.
- Read-only MCP mode with seven read tools, archive doctor, printed client
  configuration, an offline skill installer with guarded upgrade/restore, and a
  consistent SQLite online-backup helper.
- Studio adds project browsing, full records, unified search, deliberate context
  suggestions and selected Markdown briefs. The desktop download is a macOS
  Apple Silicon preview; other desktop platforms remain separately scoped.
- Complete setup, architecture, API, workflows, troubleshooting, security and
  data-safety guides. New source/advisory checks, immutable workflow action refs,
  least-privilege publication and artifact provenance.

The server remains Rust/SQLite over local stdio. Schema 1 and existing tool input
contracts are preserved. Prebuilt server binaries need no Rust, Node.js, model
API key or database service. The skill installer/backup helpers use Python 3.11+.
The MCPB includes universal macOS, Linux x64 and Windows x64 server binaries.

Byte limits measure canonical serialized MCP results; token estimates are
heuristics and do not measure provider usage or guarantee cost savings. Saved
text is untrusted reference data, and historical checks need current verification.
The AI client controls what retrieved memory reaches its model.

Archives are plaintext, and read-only SQLite can maintain WAL/SHM coordination
files. Binaries are not Developer ID signed or notarized. The current security
guide records upstream desktop dependency warnings and the scope of checks;
no blanket malware-free or all-platform runtime guarantee is made.

Start with README.md and docs/quickstart.md. Verify SHA256SUMS.txt and the release
artifact provenance before using downloads.
