# Project Memory Studio — macOS Apple Silicon preview

Open **Project Memory Studio.app**. Studio looks for the same local SQLite
archive as Project Memory MCP. Use **Open database** to choose another existing
archive, or explore the clearly labeled synthetic sample workspace.

Choose a project, open a complete record, then add it to a context brief.
Search finds literal text across notes, decisions and handoffs. **Suggest
context** retrieves a bounded whole-record selection; review it before using
Add or Replace. Copy Markdown or use the native save dialog when ready.

Your memories remain local. Studio opens records read-only; SQLite may maintain
WAL/SHM coordination files. The app does not create missing memory archives.
Your AI client separately controls what retrieved information reaches a model.

This preview is for macOS on Apple Silicon (arm64). Its executable has an
ad-hoc signature, no Developer ID identity or notarization. Follow your OS trust
controls. Other desktop platforms have separate verification/distribution limits.
